#Sistema de Gestión de Empleados

## Descripción 
Proyecto desarrollado en Python para practicar programación y control de version con Git y GitHub

##Funcionalidades
- Mostrar una lista de empleados.
- Contar el número total de empleados
- Buscar empleados por nombre
- Eliminar empleados
- Actualizar empleados

## Tecnologías
- Python
- Git
- GitHub
- SQLite

## Cómo ejecutar
1. Tener Python instalado.
2. Descargar o clonar el repositorio
3. Ejecutar `python empleados.py`

## Base de datos
- Se utiliza sqlite que ya esta en las herramientas de python

## Aprendizajes
- Practique la creacion de una aplicacion CRUD desde la consola
- Practique logica con python 
- Tambien, la implementacion de una base de datos con python y su manejo con SQLite
