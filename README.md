#Sistema de Gestión de Empleados

## Descripción 
Proyecto desarrollado en Python para practicar programación y control de version con Git y GitHub

##Funcionalidades
- Mostrar una lista de empleados.
- Contar el número total de empleados
- Buscar empleados por nombre

## Tecnologías
- Python
- Git
- GitHub

## Cómo ejecutar
1. Tener Python instalado.
2. Descargar o clonar el repositorio
3. Ejecutar `python empleados.py`

## Estado del proyecto
Proyecto de aprendizaje en desarrollo.
